# Guion de video demo Dorian

Duracion sugerida: 3 a 4 minutos

## Escena 1 - Apertura
Tiempo: 0:00 a 0:15

Visual:
- Pantalla de portada con logo Dorian
- Titulo: `Dorian Platform`
- Subtitulo: `Web publica + panel admin + app movil + backend centralizado`

Narracion:
`Dorian es una plataforma digital integral para gimnasios que conecta captacion, operacion interna y experiencia del cliente desde un solo sistema.`

## Escena 2 - Web publica
Tiempo: 0:15 a 0:55

Visual:
- Abrir `https://dorian-public-site.vercel.app`
- Mostrar hero principal
- Bajar a planes, promociones, clases y sedes

Narracion:
`La web publica ya funciona como canal comercial y de marca. Desde aqui el usuario puede conocer la propuesta del gimnasio, revisar planes, promociones, clases y sedes, y avanzar hacia la descarga de la app o el contacto comercial.`

## Escena 3 - Panel administrativo
Tiempo: 0:55 a 1:55

Visual:
- Abrir `https://dorian-admin-panel.vercel.app/login`
- Ingresar con:
  - correo: `superadmin@dorian.test`
  - clave: `Pass1234!`
- Mostrar dashboard
- Entrar a sucursales
- Entrar a clases
- Entrar a promociones
- Entrar a membresias
- Si da tiempo, mostrar clientes o staff

Narracion:
`Este es el panel administrativo. Desde aqui el negocio puede gestionar sucursales, clases, promociones, membresias, clientes y personal operativo. El objetivo es centralizar la operacion en una sola plataforma, con una sola fuente de informacion.`

## Escena 4 - App movil
Tiempo: 1:55 a 3:10

Visual:
- Abrir la app Android o Flutter web local si la usas para demo
- Login con:
  - correo: `customer@dorian.test`
  - clave: `Pass1234!`
- Mostrar home
- Mostrar promociones
- Mostrar clases
- Mostrar plan
- Mostrar ejercicios
- Mostrar perfil

Narracion:
`La app movil extiende la relacion con el cliente. Aqui el usuario puede gestionar su experiencia dentro del gimnasio: ver su membresia, revisar promociones, reservar clases, consultar ejercicios, seguir su plan y acceder a su perfil fitness.`

## Escena 5 - Cierre comercial
Tiempo: 3:10 a 3:40

Visual:
- Volver a una slide final o a una pantalla de cierre con logo

Narracion:
`Dorian no es solo una web o una app. Es una base real para operar digitalmente un gimnasio o una cadena de gimnasios, y puede comercializarse como venta del proyecto o como plataforma mensual administrada.`

## Flujo recomendado si la audiencia es comercial
- web publica
- app movil
- panel admin

## Flujo recomendado si la audiencia es operativa
- panel admin
- app movil
- web publica

## Apoyo para la grabacion
- Habla con frases cortas
- No leas cada pantalla
- Enfatiza que ya existe un backend central
- No prometas pagos reales automatizados todavia
- Cierra con el modelo comercial que vayas a ofrecer
